# ABcode（本 AI Agent）与成熟 AI Agent 产品能力对比与优化清单

生成时间：2026-08-07

## 当前能力基线（ABcode 工具集）
| 工具 | 能力类型 |
|------|---------|
| get_current_time | 时间获取 |
| web_search | 联网搜索 |
| fetch_url | 抓取网页文本 |
| list_files / read_file / write_file | 工作区文件读写 |
| run_shell | 执行只读/安全命令 |

## 与成熟产品（Claude Code / OpenAI Operator / Cursor / Devin / Manus）的差距
| 能力维度 | 成熟产品 | ABcode | 差距 |
|---------|---------|--------|------|
| 浏览器自动化 | 可操控网页、点击、填表、截图 | 无 | 缺 |
| 视觉理解 | 读图、截图、UI识别 | 无 | 缺 |
| 计算机操作 | 键鼠模拟、系统级操作 | 仅只读命令 | 缺 |
| 长时记忆 | 跨会话记忆偏好 | 会话间不保留 | 缺 |
| 能力扩展 | MCP 插件协议 | 固定工具集 | 缺 |
| 纵深执行 | 改代码、跑服务、装依赖 | 仅只读 shell | 受限 |

## 核心短板总结
1. run_shell 只读 → 无法真正"做事"
2. 无视觉 → 不能看图、UI、设计稿
3. 无浏览器自动化 → 不能填表、点按钮、抓动态页面
4. 无长时记忆 → 反复犯错（如反复空转不调用工具）
5. 工具不可扩展 → 无法挂装新能力

## 优化建议（优先级排序）
### P0
- run_shell 增加写权限（沙箱隔离）
- 引入浏览器控件：open_url / click / fill / screenshot
- 引入多模态绘图识别：analyze_image

### P1
- 增加个人偏好记忆文件 profile.json（跨会话）
- 行为反思：每次任务结束写入经验，避免重复踩坑
- 行动准则：先动手调用工具，再说话，避免空转

### P2
- 支持 MCP（Model Context Protocol），工具可插拔
